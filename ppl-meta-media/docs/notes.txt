Now lets write a users manual with with the following information:

pl-meta-mini age estimation back-end headless app

The scope of the app is for this endpont to run as a headless app that gets short videos
of 1-3 seconds duration and returns results regarding their age estimation and particular whether
the people detected are adults or underaged people.
The application returns this:

The ppl-meta-mini age estimation back-end headless app is stored here: https://we.tl/t-5SGZZtgCrl and will be
available until Fri 31 Jul 2025 (link will be updated in a later date)

Version: Beta085 with complete DeepFace age detection support

How to run the app in a linux OS:

In an docker enabled machine, download from https://we.tl/t-5SGZZtgCrl

From the download directory run:
# Linux:
docker load -i ppl-meta-mini-beta085.tar
# Windows CMD:
docker load < ppl-meta-mini-beta085.tar

At docker desktop when running the image fill in the port for localhost (e.g. 8005)
The application, swagger front-end will be accessible at localhost:8005/docs

Use:

The endpoint to use is:
curl -X 'POST' \
  'http://0.0.0.0:8004/api/v1/upload-and-analyze?max_faces_per_frame=10&proximity_threshold=50&confidence_threshold=0.5&frame_interval=15' \
  -H 'accept: application/json' \
  -H 'Content-Type: multipart/form-data' \
  -F 'file=@009-indoors-bodycam-line.mp4;type=video/mp4'

http://0.0.0.0:8004/api/v1/upload-and-analyze?max_faces_per_frame=10&proximity_threshold=50&confidence_threshold=0.5&frame_interval=15

The arguments are:

max_faces_per_frame: leave the default 10, it is not recomented to change it to 2 or 1.
proximity_threshold:" this is a placeholder foo argument - leave or change it, it wont have an effect
confidence_threshold: the 0.5 value is the recomented one. Less than 0.5 could produce false positives in face detection, more than 0.6 might
miss a person due to frame photo quality being not ideal.
frame_interval: for videos of the recomented duration of 1-2 seconds, the recomented value for frame_interval is from 3 to 5.
file: from swagger upload a video file. The recomented duration is 1-2 seconds for quick and reliable results even in "weak" machines.

Notes on the return data:

The people detected are ordered based on their distance from the camera. The distance measure is not meters
but it is analogous.

It is recomented to utilise the data of the nearest person each time. Note that one person in real life 
could have more than one data set in the return data (due to motion) but the closer one is the representative one.

The age estimation value is analogous to the real world age but it deviates as the photo deviates
 from the perfect photo environment: Near the camera, with plenty of ampient light and with no distortion
 or movement in the frame.
 
 Since the case is never the optimal, acceptable value ranges for a age estimation with high confidence (80%)
 are the following:

 The alert for the underaged peopple should be fired when the "estimated_age" is less than 30
 AND 
 "distance" in no more than 10. Also, less than 2 is a false positive.
 "quality_score is more than 0.250

Notes on the quality assurance feedback data for further algorithm training:

The app keeps the video files at the location mentioned in the "storage_path" value.
The app automatically erases all videos but the three most recent ones, every time the endpoint is executed.
For feedback/training provide the last three videos along with their return data.
