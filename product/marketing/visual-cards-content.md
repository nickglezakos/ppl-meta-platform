## Format A — Social Media Cards

### Dimensions & Platforms

| Platform | Aspect Ratio | Resolution | Notes |
|---|---|---|---|
| Instagram Feed | 1:1 | 1080 × 1080 px | Primary format — design here first |
| Instagram Story / Reels | 9:16 | 1080 × 1920 px | Re-crop: punchline top, sub-punchlines bottom |
| LinkedIn / Facebook | 1.91:1 | 1200 × 628 px | Landscape — punchline centred, sub-punchlines below |
| Twitter / X | 16:9 | 1600 × 900 px | Same layout as LinkedIn |

### Layout Rules

- **Background**: Full-bleed hero image (persona/scene) covering the entire card
- **Punchline**: Top 30-40% — bold, large (48-64pt equivalent), white or brand-accent, with a subtle text-shadow or dark blur backing for legibility
- **Sub-punchlines**: Bottom 25% — 3 lines, smaller (18-24pt), over a semi-transparent dark gradient band (60-80% opacity)
- **Hardware icons**: Small monochrome icon row between punchline and sub-punchlines, or tucked into the gradient band
- **Brand mark**: EyeNet Vision logo — bottom-right corner, white, 8-10% of card width
- **No heavy text frames**: Let the image breathe — text floats on the photo with shadow/gradient, never in opaque boxes

## Format B — Website Full-Width Rows

### Layout Spec

Each card becomes a full-width horizontal section (row) on the website, alternating image side for visual rhythm.

```
Row 1  [IMAGE LEFT  55%] [TEXT RIGHT 45%]   ← Card 1
Row 2  [TEXT LEFT  45%] [IMAGE RIGHT  55%]   ← Card 2
Row 3  [IMAGE LEFT  55%] [TEXT RIGHT 45%]   ← Card 3
Row 4  [TEXT LEFT  45%] [IMAGE RIGHT  55%]   ← Card 4
...alternating...
```

### Text Column Structure

```
[H2]  Punchline
[p]   Sub-punchline 1
[p]   Sub-punchline 2
[p]   Sub-punchline 3
[icons] Hardware icon strip (inline, small, monochrome)
[CTA button]  "Action Text" → links to product/demo page
```

### Image Column

- Hero image at full height of the row, `object-fit: cover`
- Light digital overlays (bounding boxes, heatmaps, glow effects) composited into the image
- Optional: subtle parallax scroll or scale-on-hover for engagement
- Images should be optimised at **1200 × 800 px** minimum, 2x for retina

### Responsive Behaviour

- Below 768px: stack vertically — image on top (full width, 16:9 crop), text below
- Punchline becomes H3 size on mobile
- CTA button becomes full-width on mobile

## General Design Notes

| Element | Guideline |
|---|---|
| **Typography** | Sans-serif, bold weight for punchlines (e.g., Inter, Poppins, or brand font) |
| **Punchline** | Title case, 6-12 words, never wraps beyond 2 lines |
| **Sub-punchlines** | Italic or regular weight, sentence case, one line each |
| **Hardware icons** | Monochrome line icons, 24-32px, evenly spaced, brand-tinted |
| **Photography style** | Real-world settings with light digital overlays — avoid stock-photo sterility |
| **Brand mark** | Always present — white logo on dark images, dark logo on light images |
