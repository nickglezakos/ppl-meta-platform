## 3. Model Usage Patterns

### 3.1 Primary Detection Pipeline
```
Input Image
    ↓
1. Haar Cascade (haarcascade_frontalface_default.xml)
    ↓ [Optional fallback]
2. SSD ResNet-10 (res10_300x300_ssd_iter_140000.caffemodel)
    ↓ [Face regions detected]
3. dlib Shape Predictor (shape_predictor_68_face_landmarks.dat)
    ↓ [68 landmarks extracted]
4. FaceNet InceptionResnetV1 (auto-downloaded)
    ↓ [512-d embeddings]
5. Age/Gender Classification (age_net.caffemodel, gender_net.caffemodel)
    ↓
Final PersonPrint Record
```

### 3.2 Comparison Pipeline
```
Face Embedding 1 ←→ Face Embedding 2
         ↓
    Cosine Similarity
         ↓
    Threshold Decision (0.70)
         ↓
    Match/No Match + Confidence Score
```

- **MTCNN + FaceNet**: Higher accuracy path via `face_comparer.py`
