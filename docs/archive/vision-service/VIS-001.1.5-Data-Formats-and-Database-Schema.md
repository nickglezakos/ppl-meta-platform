### 1.2 Primary Data Tables

#### PersonPrints Table (Core Identity Records)
```sql
CREATE TABLE IF NOT EXISTS "PersonPrints" (
    ID INTEGER PRIMARY KEY,              -- Auto-increment record ID
    UniqueID TEXT,                       -- UUID for face instance
    Location TEXT,                       -- Geographic location
    Time REAL,                           -- Timestamp (Unix epoch)
    Gender TEXT,                         -- Gender classification (Man/Woman)
    AgeGroup TEXT,                       -- Age classification (numeric)
    AgeRange TEXT,                       -- Age range estimation
    PicPath TEXT,                        -- Path to face image file
    TakeUID TEXT,                        -- Video capture session ID
    TakeTime REAL,                       -- Capture timestamp
    Device TEXT,                         -- Recording device identifier
    PersonUID TEXT,                      -- Person identity grouping ID
    FacenetEmbeddings BLOB,              -- 512-d face embeddings (2048 bytes)
    pproute TEXT,                        -- JSON positioning data
    camera_id INTEGER,                   -- Camera device reference
    image_quality REAL,                  -- Image quality score
    Descriptors BLOB                     -- ORB feature descriptors (variable size)
);
```

**Data Format Details:**
- **UniqueID**: UUID4 format (e.g., `fe9145a8-6a1c-4a36-89e3-d158e71a587b`)
- **FacenetEmbeddings**: 2048 bytes (512 float32 values)
- **Descriptors**: Variable size ORB keypoint descriptors (320-9696 bytes)
- **pproute**: JSON string containing positioning and metadata
- **image_quality**: Float score (6.5-15.5 typical range)

#### FaceRects Table (Bounding Box Data)
```sql
CREATE TABLE FaceRects (
    Id INTEGER PRIMARY KEY,
    RawDetectionDataId INTEGER,          -- Foreign key to detection frame
    rect_x INTEGER,                      -- Bounding box X coordinate
    rect_y INTEGER,                      -- Bounding box Y coordinate
    rect_width INTEGER,                  -- Bounding box width
    rect_height INTEGER,                 -- Bounding box height
    grouptags REAL,                      -- Group classification score
    persontabs REAL,                     -- Person tracking score
    FOREIGN KEY (RawDetectionDataId) REFERENCES RawDetectionData (Id)
);
```

#### RawDetectionData Table (Frame Storage)
```sql
CREATE TABLE RawDetectionData (
    Id INTEGER PRIMARY KEY,
    frame BLOB,                          -- Raw image frame data
    timestamp REAL,                      -- Frame timestamp
    frame_path TEXT                      -- Path to frame file
);
```

#### FacePics Table (Face Image References)
```sql
CREATE TABLE FacePics (
    Id INTEGER PRIMARY KEY,
    RawDetectionDataId INTEGER,          -- Link to detection frame
    face_pic TEXT,                       -- Path to cropped face image
    FaceDetectionFilter INTEGER,         -- Detection algorithm used
    age INTEGER,                         -- Age estimation
    gender TEXT,                         -- Gender classification
    FOREIGN KEY (RawDetectionDataId) REFERENCES RawDetectionData (Id)
);
```

## 2. Data Format Specifications

### 2.1 Face Embedding Format

#### FaceNet Embeddings (BLOB Storage)
- **Size**: 2048 bytes (fixed)
- **Type**: Float32 array (512 dimensions)
- **Encoding**: `numpy.ndarray.tobytes()`
- **Decoding**: `numpy.frombuffer(blob, dtype=np.float32)`
- **Range**: Normalized values (-1.0 to 1.0)
- **Purpose**: Face similarity comparison via cosine distance

```python
# Storage format
facenet_embeddings_np = facenet_embeddings.detach().cpu().numpy()  # [512,]
facenet_embeddings_bytes = facenet_embeddings_np.tobytes()          # 2048 bytes

# Retrieval format
embeddings = np.frombuffer(embeddings_blob[0], dtype=np.float32)    # [512,]
```

#### ORB Descriptors (Variable BLOB Storage)
- **Size**: Variable (320-9696 bytes observed)
- **Type**: OpenCV ORB feature descriptors
- **Encoding**: `numpy.array(descriptors).tobytes()`
- **Format**: Binary feature descriptors for keypoint matching
- **Purpose**: Traditional computer vision feature matching

### 2.2 Image Data Formats

#### Face Image Files
- **Directory**: `/ppl-meta/face_pics/`
- **Format**: JPEG images
- **Naming**: UUID-based filenames
- **Size**: Variable (cropped face regions)
- **Color Space**: RGB
- **Typical Resolution**: Variable based on detection size

#### Frame Storage
- **Directory**: `/ppl-meta/frames/`
- **Format**: JPEG/PNG frames
- **Source**: Video frame extraction
- **Database Storage**: Optional BLOB storage in RawDetectionData
- **Dual Storage**: File system + database references

#### Video Processing
- **Input Formats**: MP4, WebM, AVI
- **Processing**: OpenCV VideoCapture
- **Frame Extraction**: Sequential frame-by-frame processing
- **Output**: Individual frame files + face crops

## 3. Data Flow Pipeline Analysis

### 3.1 Video Processing Pipeline

```
Input Video File
    ↓
Frame Extraction (OpenCV)
    ↓ [Per frame]
Face Detection (Haar/SSD/MTCNN)
    ↓ [Per detected face]
Face Cropping & Storage
    ↓
Bounding Box Recording (FaceRects)
    ↓
Raw Frame Storage (RawDetectionData)
    ↓
Face Image Reference (FacePics)
```

### 3.2 Face Processing Pipeline

```
Face Image
    ↓
Facial Landmark Detection (dlib 68-point)
    ↓
Face Normalization & Alignment
    ↓
Feature Extraction:
    ├── FaceNet Embeddings (512-d)
    ├── ORB Descriptors (variable)
    └── Age/Gender Classification
    ↓
PersonPrint Record Creation
    ↓
Database Storage (PersonPrints table)
```

### 3.3 Face Comparison Pipeline

```
Query Face → FaceNet Embedding Extraction
    ↓
Database Search (PersonPrints.FacenetEmbeddings)
    ↓
Cosine Similarity Calculation
    ↓
Threshold Filtering (similarity > 0.70)
    ↓
Match Results with Confidence Scores
```

### 3.4 Person Grouping Pipeline

```
Individual PersonPrints
    ↓

    ↓
Clustering Algorithm (DeepFace binding)
    ↓

    ↓
```

## 4. Data Transformation Patterns

### 4.1 Image Preprocessing

#### Face Normalization
```python
# Standard preprocessing pipeline
1. Color Space Conversion: BGR → RGB
2. Face Detection: Multiple algorithms (Haar/SSD/MTCNN)
3. Bounding Box Extraction: (x, y, w, h)
4. Face Cropping: ROI extraction
5. Landmark Detection: 68-point facial landmarks
6. Alignment: Based on eye positions
7. Normalization: Size standardization
```

#### Feature Extraction
```python
# Multi-modal feature extraction
FaceNet Embeddings:
    Input: Aligned face image (RGB)
    Process: InceptionResnetV1 forward pass
    Output: 512-dimensional float32 vector
    
ORB Descriptors:
    Input: Grayscale face image
    Process: OpenCV ORB keypoint detection
    Output: Variable-length binary descriptors
    
Age/Gender:
    Input: 227x227 RGB face
    Process: Caffe CNN models
    Output: Age group (string) + Gender (string)
```

### 4.2 Database Serialization

#### Binary Data Storage
```python
# FaceNet embeddings serialization
torch_tensor → numpy_array → bytes → SQLite BLOB
embeddings.detach().cpu().numpy().tobytes() → database

# ORB descriptors serialization  
opencv_descriptors → numpy_array → bytes → SQLite BLOB
np.array(descriptors).tobytes() → database

# Binary data retrieval
SQLite BLOB → bytes → numpy_array → processing_format
np.frombuffer(blob, dtype=np.float32) → embeddings
```

#### JSON Serialization
```python

positioning_data = {
```

### 6.2 Query Performance Patterns

#### Indexing Strategy
```sql
-- Recommended indexes for performance
CREATE INDEX idx_personprints_uniqueid ON PersonPrints(UniqueID);
CREATE INDEX idx_personprints_personuid ON PersonPrints(PersonUID);
CREATE INDEX idx_personprints_takeuid ON PersonPrints(TakeUID);
CREATE INDEX idx_facerects_rawdetectionid ON FaceRects(RawDetectionDataId);

```

#### Common Query Patterns
```sql
-- Face similarity search (frequent)
SELECT PicPath, FacenetEmbeddings, image_quality 
FROM PersonPrints 
WHERE PersonUID != 'unknown'
ORDER BY image_quality DESC;

-- Session-based queries
SELECT * FROM PersonPrints 
WHERE TakeUID = ?
ORDER BY Time;

-- Camera-based filtering
SELECT pp.* FROM PersonPrints pp
JOIN Personprints2Cameras p2c ON pp.ID = p2c.PersonPrintId
WHERE p2c.CameraId = ?;
```
