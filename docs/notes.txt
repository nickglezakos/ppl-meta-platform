Single collection ppl_thread workflows

First level ppl_thread workflow for a single collection.

The first level ppl_thread workflow detects person objects for a single camera or user collection. 
It is executed automatically each time faces are stored for this collection 
from a face detection workflow.
After processing the faces to result to person objects the ppl_thread workflow
stores the person objects in the vision service database. The person objects can be traced
back to which face objects they were produced by.

Second level ppl_thread workflow for a single collection.

The second level ppl_thread workflow conducts the following:
1. Its detection end time is equal to the end time of the most recent first level workflow's 
   end time for the same collection.
2. Its detection start time is its detection end time minus the detect duration as it is declared 
   at settings.
3. It results to persons objects detected within its detect time and end time.
4. It relates the person object detected to the face objects it detected them from. 
5. After finishing the person object detection it finds possible person object duplicates based on 
   settings criteria. Duplicates found are merged in the sense that they refer to the one person
   object UUID. Also relations to faces for person object merged are updated.
6. It updates the ppl_thread time start and time end second level status.
7. It stores the person object results to a dedicated person object collection created if it
   does not exists that is related to the source collection.

Third level ppl_thread workflow for a single collection.

1. The third level ppl_thread workflows are executed in idle time as it is set in settings.
2. Third level ppl_thread workflows find person object duplicates follwing the exact same
   duplicate criteria applied for the seond level workflows but for a more extended detection
   time. Their detection time is set in the settings.
3. It stores the merged person objects in the same dedicated person object collection created if it
   does not exists that is related to the source collection.

ppl_thread workflows for multiple collections (groups of camera and/or user collections)

1. For the required time period the ppl_thread workflow for a group of collections detects if there
   are second or third level person objects produced by previous second or third level singe 
   collection workflows. For the time spans that there are not any it executed second level 
   workflows for each single member collection of the group.
2. After all member collections of the group have been processed for person object it finds Additional
   merges duplicates for any member collection that has not been processed by a third level
   workflow separatelly.
3. After all member collections are processed for second level the workflow processes the person 
   objects of the group for duplicates and merges the person objects accordingly.
4. It stores its results to a dedicated ppl_thread person object collection.
5. It stores the person object results to a dedicated person object collection created if it
   does not exists that is related to the source member collections.


User defined person object searches

When a user asks for person objects for a collection or a group of collections 
for a specific time span the system carries out the following:
1. It checks if there are thrid level workflows results for the entire this time period or the
   required search. If there are then it simply returns the person objects.
2. If there are time spans that are part of the required search time span with no third
   level workflows results but with second level ones that it again returns the person
   objects with a notification mesasage that more process it due on the returned results.
3. If there are time spans that are part of the required search time span with no second level
   level workflows results it first carries out the missing second level workflows and then 
   return the person object results with a notification mesasage that more process it due on 
   the returned results.
