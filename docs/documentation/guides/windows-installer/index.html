Install EyeNet on Windows
in plain English

Follow these steps on a normal Windows desktop or laptop (Intel/AMD). You do not need to build software. You download one installer file, answer a few prompts, and open a web page.

https://eyenet-vision.com/

Quick facts

PC type Windows 10 / 11 (64-bit Intel/AMD)
Not supported Windows on ARM (e.g. some Surface)
Release 2.25.81
RAM needed 16 GB or more
Free disk 12 GB or more
Images 9 services from GHCR
Open the app at http://localhost:3000
Updated 13 Sep 2026
1

What this does (and does not do)

EyeNet runs as Docker containers on your PC. The installer pulls ready-made images tagged 2.25.81 from GitHub Container Registry. No Python, no Node, no database install by hand.

You will

  • Install Docker Desktop (once)
  • Double-click install-platform.bat
  • Log in to GHCR when asked (token)
  • Wait while images download and start
  • Open the browser and activate ownership (bootstrap)

You will not

  • Compile the product
  • Run Flutter or GitHub Actions on the customer PC
  • Need Linux skills (Docker Desktop handles that)

One file to start: install-platform.bat from deployment/windows-installer/. Put it anywhere (Desktop is fine). It can download the other installer files for you.

2

Before you start — checklist

Computer 16 GB+

Windows 10 or 11, 64-bit Intel or AMD. At least 16 GB RAM and 12 GB free disk (SSD preferred).

Docker Desktop On

Install from docker.com. Use the WSL 2 backend. Leave Docker running (whale icon steady in the tray).

From EyeNet Keys

Have ready: approved owner email and application key starting with lic_… (Authority). Also a GitHub token that can read packages.

GitHub token (so Docker can download images)

Images live on a private registry: ghcr.io/nickglezakos/ppl-meta-platform. You need a Personal Access Token with at least read:packages.

  1. Open github.com/settings/tokens
  2. Create a classic token (or fine-grained with Packages read)
  3. Enable read:packages (or use a token that already has write:packages)
  4. Copy the token and keep it handy — you paste it when the installer asks to log in to ghcr.io
Username for login is usually your GitHub username (for EyeNet builds: nickglezakos). Password = the token, not your GitHub account password.
3

Install — click through the wizard

1 Get the installer

Copy install-platform.bat onto the Windows PC (from your EyeNet package or from the repo folder deployment/windows-installer/). Optional: also copy docker-compose.windows-installer.yml and .env.windows.template into the same folder — if they are missing, the bat file tries to download them.

2 Start Docker Desktop

Open Docker Desktop and wait until it says it is running. Do not continue while it is still “starting”.

3 Double-click install-platform.bat

If Windows SmartScreen asks, choose More info → Run anyway (only if you trust this EyeNet file).

On first run you should see the EyeNet Platform Manager. Choose [1] Install / Reconfigure Platform (or press Enter if that is the default).

4 Answer the installer’s questions

The installer walks through about nine steps. In plain language:

StepWhat it asks / doesWhat you do
1Install folderPress Enter for C:\ppl-meta-platform, or type another empty folder
2RAM check (≥16 GB)If it fails, use a PC with more RAM
3Disk space (≥12 GB free)Free space if needed
4Docker running?Start Docker Desktop, then retry
5WSL memory (aims for 12 GB)Allow updating .wslconfig if prompted; restart Docker if asked
6Download companion filesNeeds internet; wait
7Credentials / .env.windowsFill prompts (DB password, etc.). Keep RELEASE_TAG=2.25.81
8Pull 9 Docker imagesLog in to ghcr.io with your token when asked; wait 5–15+ minutes
9Start containersWait until it says the platform is running

5 Open the app

When you see success, open a browser on the same PC:

http://localhost:3000
If the app sends you to /bootstrap, that is normal on first start. Enter the Authority-approved owner email and the lic_… application key. After success you should land on /home.

5

Day-to-day (still simple)

Start / stop

  1. Start Docker Desktop
  2. Double-click install-platform.bat in the install folder
  3. Choose Start or Stop from the menu

Or in PowerShell from the install folder:

docker compose -f docker-compose.windows-installer.yml --env-file .env.windows up -d
docker compose -f docker-compose.windows-installer.yml --env-file .env.windows stop

Update to a newer release (later)

  1. Confirm EyeNet published the new tag on GHCR
  2. Stop the stack
  3. Edit .env.windows → set RELEASE_TAG to the new version
  4. Pull and start again (or re-run Install from the bat)

What got installed

Nine app images (node, media, gateway, orchestrator, discovery, communications, frontend, vision-protected, vmeta-protected) plus PostgreSQL and Redis — all via Docker Compose.

If something goes wrong

SymptomTry this
Installer says Docker not runningOpen Docker Desktop; wait until fully started; run the bat again
RAM check failedNeed ≥16 GB physical RAM for this release standard
Not enough diskFree ≥12 GB; in Docker Desktop use Clean / Purge unused data
Cannot pull images / unauthorizeddocker login ghcr.io with GitHub user + PAT (read:packages); then retry install
manifest unknownWrong tag — confirm RELEASE_TAG=2.25.81 and that that tag was published
WSL memory warningAllow the installer to write %UserProfile%\.wslconfig (12 GB / 6 CPUs / 2 GB swap), then restart Docker Desktop
Container keeps restartingCheck logs from bat menu [5]; often missing or wrong Authority credentials in .env.windows
Bootstrap failsUse the approved owner email and valid lic_… key from Authority
Port already in useStop the other app using 3000 / 8080 / 5433 / 6379 / 8000–8009, or change ports in .env.windows
docker compose -f docker-compose.windows-installer.yml --env-file .env.windows logs --tail=100
