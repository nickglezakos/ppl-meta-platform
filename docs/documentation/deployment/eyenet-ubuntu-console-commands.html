EyeNet up, down, start, stop, restart & health

Local Docker Compose commands for a native Ubuntu install (~/eyenet-platform). For install, hardware, bootstrap and channel ops see wiki.eyenet-vision.com.

1

Where these commands run

Open a terminal on the Ubuntu host (for example eyenet2 or eyenet-demo) as user eyenet. The stack lives under ~/eyenet-platform with Compose project name pplmeta.

AccessURL
On the machinehttp://127.0.0.1:3000
Work LAN (example eyenet2)http://192.168.9.8:3000
Tailscale meshhttp://<mesh-ip>:3000

UI, gateway and discovery bind on the host; phones and other devices must use ADVERTISE_HOST (LAN IP), not 127.0.0.1.

2

Shared context (once per shell)

# Shared context — run once per terminal session
cd ~/eyenet-platform
export COMPOSE="docker compose --project-name pplmeta --env-file .env -f docker-compose.yml"
3

EyeNet up / start

Create (if needed) and start all services in the background:

$COMPOSE up -d

Same effect as “Start platform” in the host tray.

4

EyeNet down / stop (remove containers)

Stop the stack and remove containers. Named volumes (Postgres, media, etc.) are kept:

$COMPOSE down
5

Start / stop without removing containers

# Start existing containers
$COMPOSE start

# Stop containers but keep them
$COMPOSE stop
6

Restart

# Soft restart of running containers
$COMPOSE restart

# Recreate containers from current images
$COMPOSE up -d --force-recreate
7

Health check

$COMPOSE ps
echo "---"
for u in \
  http://127.0.0.1:3000/ \
  http://127.0.0.1:8080/health \
  http://127.0.0.1:8006/health \
  http://127.0.0.1:8001/health \
  http://127.0.0.1:8005/health
do
  code=$(curl -sf -o /dev/null -w '%{http_code}' --max-time 5 "$u" || echo fail)
  echo "$code  $u"
done
echo "---"
grep -E '^(RELEASE_TAG|ADVERTISE_HOST)=' .env

Expect 200 on frontend and healthy statuses in compose ps. After a cold up, wait ~30–60s for healthchecks before judging failures.

8

Optional — rediscover services

Re-seed the discovery directory after up (or if mobile/LAN advertise looks stale):

bash ~/eyenet-platform/reregister-discovery-services.sh
# fallback if the install copy is missing:
# bash ~/ppl-meta-platform/deployment/windows-installer/reregister-discovery-services.sh
9

One-liners (no $COMPOSE)

# up
cd ~/eyenet-platform && docker compose --project-name pplmeta --env-file .env -f docker-compose.yml up -d

# down
cd ~/eyenet-platform && docker compose --project-name pplmeta --env-file .env -f docker-compose.yml down
