Πρόλογος demo

Μία αφήγηση. Σταθεροί ρόλοι συσκευών. Δείχνετε τις λειτουργίες και τα οφέλη σταδιακά: Βλέπω → Γνωρίζω → Δρω → Δείχνω → Επαληθεύω → Μετακινώ → Κλείνω.

03

Κλιμακούμενες σκηνές — μέρος Α

≈ 20–25 λεπτά συνολικά. Οι σκηνές 0–3 χτίζουν από το island site μέχρι live όραση, ταυτότητα και automation.

0 Island site

≈ 2 λεπτά

Ανοίξτε το UI από το IP του mobile router. Δείξτε κάμερες, signage και presence συσκευές online στο LAN του mobile router.

Σημείο: Πλήρες site EyeNet, ικανό για offline, απομακρυσμένα προσβάσιμο. Χωρίς cloud video.

1 Live όραση

≈ 3 λεπτά · Gate / Cameras / Instant Detection

Περάστε μπροστά από την Tapo A και την embedded κάμερα. Δείξτε live feed + instant detection (πρόσωπα / άνθρωποι / demographics). Προαιρετικά στρέψτε την mobile camera ώστε να δουν ότι «το τηλέφωνο = κάμερα».

Σημείο: Κάθε τύπος κάμερας γίνεται αισθητήρας.

2 Γνωστά πρόσωπα

≈ 3 λεπτά · Individual Groups + ppl_match

Ανοίξτε τα Individual Groups (Staff / VIP / Visitors — ό,τι είναι ήδη εγγεγραμμένο). Βεβαιωθείτε ότι 1–2 άτομα στην αίθουσα είναι μέλη group. Περάστε μπροστά από την Tapo A ως γνωστό πρόσωπο → δείξτε match στο Automation / last match info.

Σημείο: Αυτόματη αναγνώριση ατόμων.

3 Automation που ήδη υπάρχει

≈ 4 λεπτά · Vradar / Triggers & Actions

Ενεργοποιήστε ό,τι είναι ήδη ρυθμισμένο — μην ξαναχτίζετε live. Προτεινόμενο ζεύγος με πολλαπλά actions στο ίδιο trigger:

  • Known match → alert και/ή signage_rich_message («Καλώς ήρθες {matched_member_name}») + email + Slack (messaging_app)
  • Negated match (unknown) → alert + visitor playlist / προειδοποίηση στο signage + email + Slack (@channel αν χρειάζεται)

Ένα δεύτερο άτομο (ή σύντομη κάλυψη προσώπου) περνάει ως «άγνωστος». Ανοίξτε το email inbox και το κανάλι Slack ώστε να δουν τις ειδοποιήσεις να φτάνουν live.

Σημείο: Vradar = όραση → επιχειρηματική δράση σε οθόνη, email και Slack μαζί. Συνήθως εδώ είναι το «aha».
04

Κλιμακούμενες σκηνές — μέρος Β

Οι σκηνές 4–6 κλείνουν με την επιχειρηματική οπτική / τα οφέλη: signage, presence check-in, κινητή κάλυψη. Η σκηνή 7 είναι προαιρετική.

4 Signage ως επιχειρηματική οπτική / οφέλη

≈ 3 λεπτά · Signage + Automation

Μείνετε στο Android player. Δείξτε default playlist → το trigger αλλάζει playlist ή rich overlay (καλωσόρισμα / επισκέπτης / promo). Προαιρετικά demographic trigger (π.χ. people_count ≥ 2 → promo playlist).

Σημείο: Το Signage δεν είναι απλό σύστημα οθονών — αλλάζει αυτόματα από τους κανόνες του EyeNet.

5 Presence check-in

≈ 4 λεπτά · Presence

Χρησιμοποιήστε το Presence app + κάμερα πόρτας (Tapo A ή embedded):

  • QR-only grant (γρήγορα)
  • Έπειτα QR + face ή camera match (υψηλότερη διασφάλιση)

Δείξτε αποτέλεσμα session + πρόσφατα presence grants.

Σημείο: Παρουσία / έλεγχος πόρτας με audit trail — όχι απλώς face alert.

6 Ίδιοι κανόνες, κινητή κάμερα

≈ 2 λεπτά · Mobile camera

Μετακινήστε την mobile camera σε δεύτερο σημείο («αποθήκη»). Δείξτε ότι ο ίδιος τύπος trigger μπορεί να εφαρμοστεί εκεί — ή ότι η search / multi-camera κάλυψη είναι το φυσικό επόμενο βήμα.

Σημείο: Η κάλυψη ακολουθεί τον χώρο· δεν κλειδώνει σε σταθερές IP κάμερες.

7 Κλείσιμο του βρόχου Προαιρετικό

≈ 2 λεπτά · Ops + VPN · μόνο αν ζητηθεί

Προαιρετικό — μόνο αν το ζητήσει ο πελάτης. Στο UI: trigger execution log, presence sessions, προαιρετική ματιά στα analytics (κίνηση / demographics στην Είσοδο). Υπενθύμιση: διαχειρίζεστε το site μέσω Tailscale ενώ κάθεται σε travel router.

Σημείο: Ops + ιδιωτικότητα + remote support χωρίς να στέλνετε video στο cloud.

08

Presence: στατιστικά, φίλτρα, PPP & HubSpot

Δείξτε ότι η παρουσία δεν είναι μόνο check-in — έχει αναφορές, φίλτρα και διασύνδεση ταυτότητας μέχρι το CRM.

A Presence Analytics & φίλτρα

Presence → Analytics · Sessions

Ανοίξτε Presence → Analytics:

  • Εύρος ημερομηνιών, summary cards, Outcomes / Client Origin donuts
  • User-Day Presence Awards — φίλτρο χρήστη και ημερομηνίας· expand για grants της ημέρας (QR / Cam / Cam & QR)
  • Μπάρες Session Modes, Grant Types, Failure Reasons, Policy Sources

Μετά Presence → Sessions: φίλτρα User, ημερομηνίες, και Filter sheet (Mode, Decision, Grant, Policy, Failure, Origin, Camera, Group, Member, Profile). Δείξτε Apply / Clear και προαιρετικά Download Excel.

Σημείο: Από ένα tap σε card/donut/bar → Sessions με τα ίδια φίλτρα. Audit trail για HR και security.

B Διασύνδεση Group members · PPP · Users

Individual Groups · Presence → People

Δείξτε την αλυσίδα ταυτότητας:

  • Group member (Individual Groups) — το πρόσωπο που αναγνωρίζει το Vradar / Presence match
  • PPP (Presence People Profile) — προφίλ παρουσίας (όνομα, email, τηλέφωνο…) που συνδέεται στο group member
  • User — λογαριασμός πλατφόρμας / Authenticator που μπορεί να συνδεθεί με το ίδιο PPP

Στο Individual Groups: εικονίδιο link σε μέλος → επιλογή / σύνδεση People Profile. Στο Presence → People: ανοίξτε το PPP και δείξτε τα συνδεδεμένα στοιχεία.

Σημείο: Ένα πρόσωπο = μία ταυτότητα από την αναγνώριση μέχρι το check-in και τον χρήστη.

C Διασύνδεση HubSpot CRM

Presence → Settings → HubSpot CRM

Ανοίξτε Settings → HubSpot CRM (αν είναι ήδη συνδεδεμένο στο demo):

  • Import επαφών HubSpot → δημιουργία / ενημέρωση PPP (External Ref = HubSpot contact id)
  • Μετά από Presence grant → post στο HubSpot (Note στην επαφή + ιδιότητες last_presence_*)
  • Επιλογή τύπων grant που στέλνονται (check_in, presence_match, verified_presence)

Αν υπάρχει live σύνδεση: τρέξτε ένα grant και ανοίξτε την επαφή στο HubSpot. Αν όχι: δείξτε την οθόνη ρύθμισης και εξηγήστε τη ροή.

Σημείο: Η παρουσία φτάνει στο CRM χωρίς χειροκίνητο logging — HubSpot first connector.
09

Γενικά Analytics (MVR)

Home → Analytics: συνολική εικόνα κίνησης, demographics και συμπεριφοράς — όχι μόνο ένα γεγονός στην πόρτα.
Πού πηγαίνετε

Ανοίξτε Analytics (MVR People Detection Analytics). Πατήστε Filters: χρόνος (π.χ. Today), συλλογή / κάμερα (π.χ. Entrance Tapo), πηγή δεδομένων.

Πηγές δεδομένων

Instant Detection (live), Video Recording, ή και τα δύο (combined) με απο-διπλασιασμό ταυτότητας.

1 Level 1

Βασικά: Total People, Active Collections, Sessions / Videos Analyzed.

2 Level 2

Time trends: Total, Peak, Average — ωριαία / ημερήσια κίνηση.

3 Level 3

Demographics: ηλικία, φύλο, ανά κάμερα.

4 Level 4

Behavioral: peak hours, visit frequency, weekly heatmap.

5 Φίλτρα

Apply → φαίνεται η μπάρα φίλτρων. Refresh για νέα δεδομένα.

6 Export

Προαιρετικά Export Analytics (π.χ. Excel) για τον αγοραστή.

Σημείο: Από το ίδιο kit (Tapo A/B + instant detection) βγαίνει operational dashboard για είσοδο, ωράρια και κοινό — χωρίς ξεχωριστό BI tool.
10

MVR People Analysis: Routes, Attendance & Search Videos

Δείξτε πώς φτάνετε στην ανάλυση ατόμων από Search / Media και τι βλέπετε σε Routes και Attendance.

1 Πώς πάτε εκεί — Search Videos / Media

Διαδρομές εισόδου στην οθόνη ανάλυσης

  • My Media / Media Preview — ανοίξτε clip κάμερας → Details (μετά το processing) → οθόνη person / MVR analysis
  • Search Videos (ή date/time MVR search στη συλλογή) → επιλογή αποτελεσμάτων → Analysis
  • Individual Groups — Camera Search ή tap σε group member → Person Objects / cross-video analysis
Σημείο: Από αναζήτηση βίντεο ή από γνωστό μέλος group φτάνετε στην ίδια οικογένεια οθονών ανάλυσης.

2 Λειτουργίες οθόνης MVR People Analysis

Tabs στην οθόνη Details / Person analysis

  • Persons / Individuals — ποιος εμφανίστηκε στο βίντεο (ή σε πολλά βίντεο)
  • Face Details — μεμονωμένες ανιχνεύσεις προσώπου όταν χρειάζεται βάθος
  • Routes — διαδρομή κίνησης στο κάδρο (Camera View + Top View· Path ή Scatter)· dwell / πέρασμα από πόρτα
  • Attendance (cross-video) — πίνακας ποιος εμφανίστηκε πότε + timeline ανά κάμερα στο παράθυρο ανάλυσης

Σημειώστε: το Attendance εδώ είναι ανάλυση εμφανίσεων στα επιλεγμένα βίντεο — σχετικό αλλά διαφορετικό από τα Presence grants (section 08).

Σημείο: Όχι μόνο «ποιος» — και «πού κινήθηκε» και «πότε εμφανίστηκε» στο παράθυρο αναζήτησης.

3 Demo beat στο kit

≈ 3–4 λεπτά αν ζητηθεί

  1. Κάντε ένα σύντομο recording ή ανοίξτε πρόσφατο clip από Tapo A / embedded
  2. Search Videos ή Media Preview → Details
  3. Δείξτε Persons → Routes → (αν multi-video) Attendance
  4. Προαιρετικά: από Individual Group member ανοίξτε την ίδια ανάλυση
Σημείο: Forensics και λειτουργική ανασκόπηση χωρίς να φύγει το video από το site.
