To set up nginx locally:

nano /opt/homebrew/etc/nginx/nginx.conf

server {
    listen 80;
    server_name localhost;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

For running the fastapi app via nginx:
sudo nginx
source venv/bin/activate
uvicorn src.main:app --host 127.0.0.1 --port 8000

For running the fastapi app via nginx with supervisor:
supervisord -c /opt/homebrew/etc/supervisord.conf
supervisorctl reread
supervisorctl update
supervisorctl start fastapi



# RUN the fastapi app *******************************************

Running Manually (with uvicorn command)
uvicorn src.main:app --host 127.0.0.1 --port 8000
nohup run:
nohup uvicorn src.main:app --host 127.0.0.1 --port 8000 &
this output logs to nohup.out.
To stop it, find the process with:
ps aux | grep uvicorn
and kill it with:
kill <PID>

Running with Supervisor:
supervisord -c /opt/homebrew/etc/supervisord.conf
supervisorctl reread
supervisorctl update
supervisorctl start fastapi

The app will keep running even after you close the terminal.
Control the app with:
supervisorctl stop fastapi (to stop)
supervisorctl start fastapi (to start)
supervisorctl restart fastapi (to restart)
supervisorctl status (to check status)
