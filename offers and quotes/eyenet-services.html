About Eyenet

EyeNet is an on-premises, edge-computing computer vision platform for human activity monitoring and intelligent automation. It transforms standard cameras into powerful machine vision nodes — tracking and regulating human activity, empowering digital signage with real-time triggers, and taking complete control of entrance and exit points.

The platform operates efficiently on standard business hardware — 16 GB RAM and a modern multi-core CPU is all that's needed. There are no GPU servers, no cloud subscriptions, and no proprietary hardware lock-in. Connect any IP camera, WiFi cam, or mobile phone — the first detection runs in minutes. Scale from a single lens to a facility-wide mesh, from one office to entire maritime fleets, all connected securely over VPN with zero cloud dependency for video or data.

Eyenet Presence

Enjoy next-level staff presence with vision powered two-factor auth.

A versatile solution for monitoring attendance and activity in specific areas such as schools, gyms, or industrial spaces. It provides detailed attendance reports and enhanced security by ensuring only authorized individuals are present.

Key Features

Eyenet Matrix

Cross-installation aggregated reporting and centralised management over secure VPN.
A typical Eyenet installation runs on a single mini PC with 16–32 GB RAM and a standard GPU — no specialised GPU hardware required — comfortably handling a 2–5 camera load per site. Eyenet Matrix is the product that scales beyond a single location: it connects multiple installations over the VPN network, unifying reporting, user management, and operational visibility across all sites from one central dashboard.

Eyenet Matrix runs alongside the primary installation in a multi-site network, providing centralised management and aggregated reporting across all member installations. Designed to operate under VPN, it communicates with member installations via their internal VPN node URLs — all cross-installation queries go over the VPN tunnel, transparently within a private network without needing public internet exposure.

Key Features

  • Aggregated Reporting — 6 Report Types: Summary, Presence, Gate Activity, Camera Events, Demographics, and Logs — each querying all member installations in parallel and aggregating results.
  • Matrix Groups & Installation Membership: Full CRUD for groups and member installations. Multi-install licensing enforcement via configurable flags.
  • User Directory & SSO (JWT-based): Centralised user management across installations with role-based access control (RBAC). Capabilities include view reports, manage groups, manage users, view logs, and full admin.
  • Degraded Mode: If some installations are unreachable, reports still return partial data with a `degraded: true` flag and an unreachable list — no single point of failure blocks visibility.
  • Result Caching: 60-second TTL report cache for responsive dashboards across distributed sites.
  • Time-Range Filtering: All reports support optional ISO-8601 timestamp query parameters for precise historical analysis.

Administrative Capabilities

  • View Aggregated Reports — Access consolidated reports across all member installations
  • Manage Matrix Groups — Create, update, and delete Matrix groups; manage installation memberships
  • Manage Users & Permissions — Add and remove users from the Matrix directory; assign access rights
  • View Aggregated Logs — Access consolidated log reports from all installations
  • Full Administrator Access — Complete administrative control over all Matrix functions
